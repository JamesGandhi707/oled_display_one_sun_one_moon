# OLED Sun and Moon Animation 🌞🌙

An animated OLED display project using an ESP32 and a 0.96-inch SSD1306 OLED display.

## Components
- ESP32 DevKit
- 0.96-inch 128×64 SSD1306 OLED
- Jumper wires

## Connections

| OLED | ESP32 |
|---|---|
| SDA | GPIO 21 |
| SCL | GPIO 22 |
| VCC | 3.3V |
| GND | GND |

## Libraries
- Adafruit GFX Library
- Adafruit SSD1306

## Upload
Open the `.ino` file in Arduino IDE, install the required libraries, select your ESP32 board, and upload the sketch.
